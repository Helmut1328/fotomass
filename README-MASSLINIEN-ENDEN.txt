FotoMaß – Design C + 2D-Skizze + einstellbare Maßlinien-Enden

Neu:
- Endstile: gefüllte Pfeile, offene Pfeile, hohle Pfeile, 45°-Schrägstriche, Punkte und Querstriche.
- Endgröße einstellbar.
- Einstellungen werden im Projekt mitgespeichert und beim Öffnen wiederhergestellt.
- Bestehende Foto-, Zeichen-, Skizzen-, Speicher- und Exportfunktionen bleiben enthalten.

Installation:
1. ZIP entpacken.
2. Dateien im GitHub-Repository durch diese Dateien ersetzen.
3. GitHub Pages veröffentlichen lassen.
4. Seite auf dem Smartphone neu laden; bei alter Darstellung Browser-Cache/PWA einmal aktualisieren.

Hinweis: Bitte nach Veröffentlichung Maßlinien zeichnen, Endstil ändern, Projekt speichern und erneut öffnen sowie PNG-Export testen.
