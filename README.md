# FotoMaß – Smartphone-Aufmaß

## Neu
- **Foto füllt die Zeichenfläche** (Fit)
- **Zoom**: Buttons +/− / Fit, Pinch-Zoom mit zwei Fingern
- **Schieben**: Werkzeug „✋ Schieben“ oder bei Zoom ins Leere ziehen
- **Fadenkreuz**: aktivierbar – Punkt liegt oberhalb des Fingers (nichts verdeckt)
- Kompaktere, übersichtlichere Oberfläche
- Kamera + Galerie getrennt
- Anfunkte, DIN-Bemaßung parallel zur Linie, Schriftgröße, Spracheingabe

## Bedienung kurz
1. Kamera oder Galerie
2. Maßlinie ziehen (Fadenkreuz bei Bedarf an)
3. Zoom mit +/− oder zwei Fingern
4. Wert tippen oder 🎤
5. PNG exportieren / speichern
