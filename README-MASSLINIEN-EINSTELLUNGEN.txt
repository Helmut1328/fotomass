FotoMaß – Bemaßung: 45°-Endstriche und Maßhilfslinien

Änderungen:
- 45°-Schrägstriche sind die Voreinstellung für Maßlinien-Enden.
- Maßhilfslinien sind standardmäßig eingeschaltet und können in den Einstellungen deaktiviert werden.
- Maßtext bleibt oberhalb der Maßlinie angeordnet.
- Der Status der Maßhilfslinien wird im Projekt gespeichert; ältere Projekte erhalten standardmäßig die aktivierte Einstellung.
- Alle übrigen Projektdateien und vorhandenen Funktionen wurden aus dem bisherigen Paket übernommen.

Hinweis:
Die vorhandenen Messobjekte speichern Endpunkte, aber keine getrennten Bauteilkanten. Deshalb werden Maßhilfslinien als kurze, einheitliche Verlängerungen an den Endpunkten gezeichnet. Für echte, frei versetzte Hilfslinien wäre ein separates Modell der Bezugskanten erforderlich.

Installation:
1. ZIP entpacken.
2. Dateien im GitHub-Repository durch die Dateien aus diesem Paket ersetzen.
3. GitHub Pages neu veröffentlichen lassen.
4. Auf dem Smartphone neu laden und Bemaßung, Speichern sowie PNG-Export testen.
