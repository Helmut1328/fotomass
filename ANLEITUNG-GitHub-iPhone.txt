FotoMaß – Hochladen und Test auf dem iPhone

1) Dateien auf GitHub ersetzen
   Ersetze im Repository (gleicher Ordner wie bisher) mindestens:
   - app.js
   - index.html
   - style.css
   - service-worker.js
   Optional ebenfalls aktualisieren: style_patch.css, README-Modus-C.txt
   Unverändert lassen (falls schon vorhanden): storage.js, speech.js, manifest.json, Icons

2) Service Worker neu laden
   Cache-Version ist jetzt fotomass-v20.
   - Desktop: Seite einmal hard-reload (Strg/Cmd+Shift+R) oder Entwicklertools → Application → Service Workers → Unregister, dann neu laden.
   - iPhone (Safari / zum Home-Bildschirm): App schließen, Safari → Einstellungen/Website-Daten ggf. leeren, oder die PWA neu vom Browser aus öffnen und zur Startseite hinzufügen. Bei Netzwerk-first sollte ein einmaliges Öffnen mit Empfang genügen.

3) Kurzer Test auf dem iPhone
   a) Foto laden (Kamera oder Galerie).
   b) Optional Rechteck um das Werkstück, auswählen, „Suchbereich setzen“.
   c) „Mögliche Maßlinien suchen“ tippen.
   d) Erwartet: gestrichelte Vorschläge auf dem Foto + Einträge in „Maßlinienvorschläge“.
   e) Einen Listeneintrag tippen → Linie wird gelb hervorgehoben.
   f) „Übernehmen“ → echte Maßlinie; ohne Referenz erscheint die Werteingabe.
   g) „Vorschläge verwerfen“ leert alle unverbindlichen Vorschläge.
   h) Bestehende Funktionen prüfen: manuelles Maß, Referenz, Zeichnen, Speichern, Export.

4) Wenn keine Verbesserung sichtbar ist
   - Sicherstellen, dass wirklich die neue app.js geladen wird (Cache v20).
   - Anderes, kontrastreiches Foto testen.
   - Suchbereich enger setzen.
